**An automated script to easily install Metasploit Framework on Termux.**

## Features

- Installs Metasploit Framework on Termux automatically.
- Downloads and configures all dependencies.
- No root access required.
- Simple one-line installation.
- Easily update Metasploit with `msfupdate` after install.

---

## Quick Installation

Paste this command into your Termux terminal to begin installation:

```bash
curl -sL https://github.com/katilmamioffical/metasploit-in-termux/raw/refs/heads/main/install.sh | bash
```

---

## Usage

After installation, launch Metasploit using:

```bash
msfconsole
```

To update Metasploit at any time, use:

```bash
msfupdate
```

---

## Requirements

- Termux (latest version)
- Android 7.0 or higher
- ~1.5GB free storage
- Internet connection
